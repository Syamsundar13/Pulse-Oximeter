Arduino-Based Pulse Oximeter

Project Overview

This project focuses on developing an Arduino-based Pulse Oximeter to monitor heart rate (BPM) and blood oxygen saturation (SpO2).

Objective

To build an embedded system that uses sensor technology to monitor pulse rate and blood oxygen levels.

Technologies Used

- Arduino
- Embedded C/C++
- Pulse Oximeter Sensor
- Sensors and Microcontrollers

Features

- Heart rate monitoring (BPM)
- Blood oxygen saturation monitoring (SpO2)
- Sensor-based health monitoring
- Arduino-based embedded system

Project Experience

I developed and tested a Pulse Oximeter prototype as part of my college project. The prototype successfully displayed heart rate and SpO2 readings.

A recreated educational version of the project is maintained in this repository. Its current code reads raw infrared sensor data and has not yet been tested with physical hardware.

Applications

- Basic health monitoring
- Fitness monitoring
- Educational embedded systems projects

Note: This is an educational project, not a medical device.
