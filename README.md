Arduino-Based Pulse Oximeter

Project Overview

The Pulse Oximeter is an embedded systems project designed to measure blood oxygen saturation (SpO2) and heart rate (BPM) using an Arduino board and a pulse oximeter sensor.

Objective

To develop an Arduino-based system that monitors a person's blood oxygen level and pulse rate using sensor technology.

Technologies Used

- Arduino UNO
- Embedded C/C++
- Pulse Oximeter Sensor
- Sensors and Microcontrollers

Features

- Heart rate monitoring (BPM)
- Blood oxygen saturation monitoring (SpO2)
- Sensor-based health monitoring
- Arduino-based embedded system

Project Experience

I developed and tested a Pulse Oximeter prototype as part of my college project. The prototype displayed heart rate and SpO2 readings.

A recreated educational version of the project is maintained in this repository. Its current code reads raw infrared sensor data and has not yet been tested with physical hardware.

Applications

- Basic health monitoring
- Fitness monitoring
- Educational embedded systems projects

Note: This is an educational project, not a medical device.
