# Arduino-Based Pulse Oximeter

## Project Overview
The Pulse Oximeter is an embedded systems project designed to measure blood oxygen saturation (SpO2) and heart rate (BPM).

## Objective
To develop a system that can monitor a person's blood oxygen level and pulse rate using an Arduino board and a pulse oximeter sensor.

## Technologies Used
- Arduino
- Embedded C/C++
- Pulse Oximeter Sensor
- Sensors and Microcontrollers

## Features
- Measures heart rate (BPM)
- Measures blood oxygen saturation (SpO2)
- Displays health readings
- Uses an Arduino-based embedded system

## Applications
- Basic health monitoring
- Fitness monitoring
- Educational embedded systems projects
